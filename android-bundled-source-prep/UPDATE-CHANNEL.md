# Bundled Online APK update channel
Package com.bigbrother.online.bundleddev, same permanent signing key and monotonically increasing build number. Startup check runs asynchronously 1.5 seconds after resume, at most once per 15 minutes per activity; no update service needed to open the interface. Dedicated GitHub prerelease bundled-online-dev is used only for APK distribution, not accounting UI/data. Supabase Storage can replace distribution after a secure publishing credential and bucket are configured; no service-role key embedded.
Update banner allows download while working, then explicit install confirmation after saving work. Android requires install unknown apps permission and its installer approval. Download verifies exact size, SHA256, package, higher version, same signing certificate; rechecks before install. Bounded HTTPS redirect allowlist, private cache and origin-scoped existing FileProvider. No silent install, no data clearing or financial writes. Device testing still required.
Release job runs only on explicitly marked dev commit or manual publish=true dispatch, after signed build verification. Production and Local untouched. Initial commit explicitly publishes development baseline for user's install; future changes are not automatically published without approval marker.
