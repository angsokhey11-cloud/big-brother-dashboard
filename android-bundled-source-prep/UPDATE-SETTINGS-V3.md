# Update UI
No native update header. Installed-only entry under existing Mobile Settings, shows installed version and status, opens native settings dialog for Check/Retry/Download/Install. Origin-scoped AndroidX listener restricted to main frame mobile dashboard; only status/open commands, never arbitrary URLs or automatic install. Centered native AlertDialog only when eligible newer signed release detected; once per version per activity; Later keeps Settings access. Download continues off UI thread and ready notification directs to Settings, explicit save-work and Android installer confirmation preserved. Resume/foreground guarded, checks nonblocking. Device verification required. Production and local unchanged.
