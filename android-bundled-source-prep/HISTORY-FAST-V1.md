# Installed Invoice History performance V1
User reported slow opening and filter freeze on bundled V3.0.4. Inspected pinned live and cached original history sources and mobile skins. Root causes in code: await location dropdown before cache/list, unnecessary master lookup even when all rows have location, repeated all-row styling and full DOM render, blocking external fonts/image library. Installed-only patch preserves original RPCs, filters, invoice IDs, permissions, actions and full matching result set. First 60 rows rendered, Show more reveals additional rows; count remains total. Parallel location dropdown, skip unnecessary location resolver, coalesce overlapping live master calls, single mobile skin injection, Android font fallback, lazy existing image library for live PNG export, no speculative cached detail prefetch (on-demand remains). Existing cache-first live handoff unchanged. No production or Local changes. Device speed and export checks pending. Signed update publication requested for development channel only.
