APK checks now read a small public JSON release asset via github.com release download instead of the REST API. CI generates the manifest only after uploading the verified signed APK, selecting the highest published version, with package, channel, version, size, digest and exact asset URL. Native client still checks allowlisted HTTPS redirects, package, version, digest and installed signing identity before installation. No GitHub token is shipped in APK. Existing versions using REST may require one manual in-place installation to migrate if rate limited. Production unchanged.
