# Native Online registered bank balance draft
Explicit Sync Bank calls bb_invoice_bank_bulk_sync with signed-in user session and route.invoice canCreate check. The native UI holds only the selected customer's rows in memory; no auto selection, persistent cache or writes. Displays USD/KHR balances separately and eligible transfers oldest first. Non-admin sale-date rule: receipt date >= invoice date. Single cross-currency allocation uses invoice rate and refuses conflicting approved rate. Multiple selections are admin-only, same-currency, Bank or Partially Paid in Bank preview; actual pilot activation and atomic settlement remain disabled. Duplicate transaction identities fail closed. Customer, currency, rate, method or sale-date changes clear selections. Before enabling Complete, verify existing bank validation RPC, authoritative remaining balances, source locks, exact cross-currency rounding, admin-only manual transaction ID, linked-customer policy and multi-bank pilot authorization. No production changes.
