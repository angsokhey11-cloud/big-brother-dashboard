# Native Online stock draft validation
Uses existing bb_sales_direct_stock_balances for warehouse and exactItems from bb_sales_open_batches for batch stock. Purchased and zero-cost quantities are separated; aggregate draft allocations reduce displayed availability. Product-specific selling units use bootstrap definitions and convert quantities to base units. Missing source data fails closed. Exact products and services only; group stock logic is not yet migrated. Availability is a read-only snapshot, not a reservation. No writes; Complete stays disabled. Must revalidate authoritative stock, dates and allocations on server at submission before release.
