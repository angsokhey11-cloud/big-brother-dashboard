# Native invoice preview and recovery adapter
V8 debug/signed build passed; all seven fake-transport recovery cases passed. V9 uses existing InvoicePdf renderer for a private, native, paginated A4 preview from a captured draft. It preserves customer contact details, selling quantity/unit/price and shows base quantity for converted units. Unsaved drafts are prominently watermarked, have no print/share/export actions and are never registered as originals. Temporary PDF is deleted on closing the dialog; only one page bitmap is retained. Existing history rendering remains unchanged for ordinary invoices.
The account-scoped durable journal now exposes a coordinator adapter; clearing is reached only after the coordinator's verifier returns confirmed for the exact ID. This adapter is not connected to a live transport. Complete remains disabled. Device visual checks, actual persistent storage instrumentation, exact SQL contract and isolated financial integration tests are release gates. No production or Local changes.
