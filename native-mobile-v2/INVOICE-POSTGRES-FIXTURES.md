# Isolated PostgreSQL transaction suite
CI uses a disposable PostgreSQL 17 service at loopback, no cloud credentials or business records. Six deployed function definitions were obtained through read-only catalog inspection and copied verbatim. Ordinary fixtures test the real core and split functions against synthetic schema, stock trigger double, historical bank guard from the existing generator repo, and synthetic permissions. Separate database runs the existing multi-bank implementation regression suite. These are server contract regression tests, not full production schema/trigger parity or Android-to-server integration. No production writes. Complete remains disabled. Latest test outcome must be checked before claiming pass.
