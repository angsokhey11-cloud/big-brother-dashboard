# Group and registered-bank draft migration
Batch groupItems are shown separately from exact products, never on direct sale. Group-specific selling units convert to base quantity, draft group allocations aggregate by code, and preflight refreshes group remaining quantities. Payload preview uses GROUP and productGroupCode/name, leaving source allocations empty for server group allocation. Do not infer member deductions or COGS client-side; test actual server allocator before production. Exact stock and group checks are separate snapshots, not reservations.
Single registered bank input has explicit read-only validation via bb_bank_validate_invoice_input using customer, transaction, actual amount/currency, invoice currency/rate and planned equivalent. No manual ID or multi-source submit; validation result is scoped to captured selection. Bank payload submission and atomic save remain disabled. No production or Local changes.
