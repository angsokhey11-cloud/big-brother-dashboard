# Native Online completion gate
Read-only preflight checks the captured invoice number/customer pair (duplicate numbers across different customers remain allowed), current warehouse or batch exact source balances and current batch selling-date window. Editable number accepts Khmer/ASCII decimal digits. Server responses with missing fields fail closed. Results describe the captured draft only, not a reservation or authorization to save. Existing verify-save RPC wrapper is available but no write/retry workflow is connected.
Before enabling Complete: verify complete payload (selling unit base conversion, group stock, due date, staff ID, bank actual currency and allocation), registered-bank validation, admin manual ID, stable server-compatible invoice identity, persistent per-account pending-save journal before request, fingerprint of entire invoice and settlement payload, verification after ambiguous response, no automatic resend, atomic bundle RPC and backend enforcement. Test all methods and stock sources using isolated fixtures, not production transactions. No invoice/stock/payment writes in this commit.
