# Online native migration
Local V2 is paused. No controller or production changes. Online UI runs native Android code, never remote HTML. Source inventory contains 69 routes from mobile-main-menu-stockcontrol-v5.js; only Invoice History currently opens. Pending routes remain visibly disabled. Route-level permission checks mirror the existing mobile dashboard, and backend policies remain authoritative. Overview uses existing staff/admin RPCs. No polling. GitHub is currently only a development/update distribution channel, not an accounting UI or data dependency. Future modules must preserve existing permission rules, transactional RPCs, currency, stock, and approval flows; test with role-specific fixtures before enabling writes. No complete feature parity is claimed.
